Privacy Policy

EAS Automation · Effective November 17, 2026

1. What EAS Automation is

EAS Automation is a private tool built and operated by a single person (the "operator") to organize documents received by email for construction-inspection projects, in the Gmail mailboxes the operator is authorized to use. It is not offered to the public and has no other users. This page explains what the tool accesses and how that information is handled.

2. Information it accesses

Only after the operator approves access on Google's consent screen, the tool can access email messages, their headers, labels and attachments in those mailboxes. It requests these Google permissions (scopes):

  • https://www.googleapis.com/auth/gmail.readonly – read-only access to messages, labels and attachments. Used by the command-line component.
  • https://www.googleapis.com/auth/gmail.modify – used by one component that can also create drafts and organize messages (labels, archive, trash). It does not permanently delete messages, and it does not send email on its own: any outgoing message requires the operator's explicit approval.

3. How the information is used

Solely to let the operator search correspondence, read messages and save attachments (plans, submittals, certifications, reports) into folders the operator chooses, and to create drafts or labels when the operator asks. It is not used for advertising, profiling, or any purpose unrelated to these features.

4. Storage and sharing

  • The developer operates no server and receives no copy of any mailbox data. What the tool handles stays on the operator's computer and in storage locations the operator controls.
  • Google access tokens are stored locally on the operator's computer and are never uploaded to a server operated by the developer.
  • Data is not sold, rented or shared with third parties.
  • When the operator asks an AI assistant (such as Claude, by Anthropic) to help with a message or attachment, the content the operator chooses to share is sent to that assistant under the operator's own account and that provider's terms. The tool does not send mailbox data to any other recipient.
  • Mailbox content is not read by anyone other than the operator through this tool.

5. Google API Services User Data Policy

EAS Automation's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention, revocation and deletion

The tool keeps no mailbox data beyond the files the operator saves. Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the tool's tokens. Saved files can be deleted at will.

7. Changes

If this policy changes, the new version will be posted on this page with an updated date.

8. Contact

For questions, use the support email address shown on the Google consent screen for this app.
